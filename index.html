Private, single-owner command-line integration for read-first Google Workspace search and document organization.

Purpose of This Application

Schuessel Workspace CLI is an owner-operated personal productivity command-line utility. It enables the account owner to search messages, inspect conversation threads, download personal document attachments (such as receipts and invoices), and optionally stage unsent email drafts for manual review.

How Google User Data Is Accessed & Protected

  • Least-Privilege Scopes: Requests read-only mailbox access (https://www.googleapis.com/auth/gmail.readonly), with optional unsent draft creation (https://www.googleapis.com/auth/gmail.compose) only when explicitly enabled by the account owner.
  • Non-Destructive Transport Policy: Automated email sending, message deletion, trashing, and mailbox filter modifications are blocked at the application transport layer.
  • Single-Owner Operation: Operated exclusively by the project owner for personal workflows; not offered as a multi-tenant public SaaS product.
