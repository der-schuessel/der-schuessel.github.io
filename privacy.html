1. Overview

Schuessel Workspace CLI is a private, owner-operated command-line application used solely by its developer/owner to access, search, and organize personal Google Workspace data. It does not onboard, collect, or store data from third-party public users.

2. Data Accessed via Google APIs

When authorized by the account owner via OAuth 2.0, the application accesses:

  • Email metadata, message bodies, conversation threads, and attachments via gmail.readonly solely at the explicit direction of the account owner.
  • Unsent email draft creation via gmail.compose only when explicitly opted into by the account owner.

3. Data Storage, Security & Sharing

  • No Third-Party Sharing or Sale: Google user data is never sold, rented, licensed, or transferred to third-party data brokers or advertisers.
  • Credential Protection: OAuth 2.0 refresh tokens are stored with restricted owner-only permissions (0600) in the owner's private environment.
  • No Model Training: Data retrieved from Google Workspace APIs is never used to train, fine-tune, or improve generalized third-party machine learning models.

4. Google API Services User Data Policy (Limited Use)

Schuessel Workspace CLI's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revocation & Deletion

Access may be revoked at any time via local credential removal (gmail-cli auth logout) or directly in Google Account settings at https://myaccount.google.com/permissions.
